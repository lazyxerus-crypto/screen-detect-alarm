# 화면 감지 알리미 (screen-detect-alarm)

단일 HTML 파일로 실행되는 화면 감지 프로그램. 외부 의존성 없음 (CDN·외부 라이브러리 불필요).

## 실행

`screen-detector-v2.html`을 브라우저에서 열기 → **화면 공유 시작**

## 기능

- 화면 공유 캡처 + 실제 해상도 표시 (원본 프레임 기준 ROI 분석)
- 전체 원본 화면에는 ROI 테두리만, 프리셋별 화면에는 불투명 HSV 마스크 표시
- 프리셋별 ROI (X·Y / W·H), HSV 범위 (듀얼 레인지 슬라이더, H 0~360°)
- 감지조건: 평균 틱 → 임계값 범위 → 연속 틱 → 알람 지연 → 계산 방식 (4방향 군집 / 8방향 군집 / 전체픽셀)
- Web Audio 알람 10종, ON 유지 중 반복, 감지 중 카드 발광 효과
- 화면 고정/해제, 겹침색(2·3·4+겹침) 랜덤 변경
- 프리셋·전체 설정 텍스트 복사/가져오기, localStorage 자동 저장
- 구조화 로그 (레벨 필터·복사)
