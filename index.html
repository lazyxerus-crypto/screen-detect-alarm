사용방법

  1. 화면 공유 시작을 눌러 감시할 화면을 공유합니다.
  2. 감지 카드 추가로 감지 카드를 만듭니다. 카드 상단의 활성화/비활성화 토글로 분석 대상을 켜고 끕니다.
  3. 감지 영역을 지정합니다 (X·Y 왼쪽, W·H 오른쪽). 원본 화면의 박스를 드래그하면 이동하고, 테두리를 드래그하면 크기를 조절할 수 있습니다.
  4. 감지 색상 범위에서 찾을 색 범위를 지정합니다. 각 감지 색상의 [색 추출]을 누른 뒤 미리보기를 클릭하면 클릭한 색과 연결된 유사색 영역이 페인트 채우기처럼 자동 채워지고, 채워진 색의 최소값(1의 자리 내림)~최대값(1의 자리 올림)으로 감지 범위가 자동 설정됩니다. 완료 시 감지 크기 범위는 현재 계산 방식(덩어리 대각선 포함/흩어진 픽셀 합산/덩어리 상하좌우)의 덩어리값 ±1로 자동 설정됩니다. (완료: 버튼 다시 클릭 / 취소: Esc)
  5. 감지조건
    • ① 평균 횟수: 최근 N회의 감지값을 평균냅니다. 1이면 그 회의 값 그대로 사용합니다.
    • ② 감지 크기 범위: 평균값이 최소~최대 픽셀 수 안에 들어야 조건을 만족합니다.
    • ③ 연속 횟수: 조건을 연속 N회 만족해야 감지가 시작됩니다. 한 번이라도 벗어나면 즉시 꺼집니다.
    • ④ 알람 대기: 감지된 뒤 N초 후에 알람이 울립니다. 기다리는 동안 감지가 꺼져도 예약된 알람은 울립니다.
    • ⑤ 크기 계산 방식: 덩어리(상하좌우만)는 상하좌우로 이어진 덩어리 중 가장 큰 것, 덩어리(대각선 포함)는 대각선까지 포함한 덩어리 중 가장 큰 것, 흩어진 픽셀 전부 합산은 조건에 맞는 픽셀 전부 개수를 감지값으로 씁니다.
  6. 알람
    • 감지 시작할 때: 감지가 시작될 때 울립니다. 대기 시간이 있으면 그만큼 기다렸다 울리고, 감지가 계속되면 2.5초 간격으로 반복됩니다.
    • 감지 끝날 때: 감지가 끝날 때 즉시 1번만 울립니다.
    • 시작·끝 둘 다: 시작과 종료 모두 울립니다.
    • 끄기: 알람을 사용하지 않습니다.
  7. 현재 화면 고정으로 화면을 멈춰서 분석할 수 있습니다.
  8. 이미지 인식은 카드의 [이미지 인식] 모드에서 사용합니다. [영역 캡처] 후 미리보기의 민트색 상자를 드래그해 기준 이미지를 지정하고 [저장]하세요. 검색 범위는 감지 영역 전체이며, 유사도가 기준(50~100%, 기본 99%) 이상이면 감지됩니다. 계산은 별도 스레드(Worker)에서 흑백 NCC 2단계 탐색+색상 확인으로 수행됩니다. 게임 해상도·UI 크기를 바꾸면 다시 캡처하세요.
  9. 카드 설정 복사는 클립보드에 복사, 카드 설정 가져오기에 붙여넣으면 새 감지 카드가 추가됩니다.
  10. 오디오 활성화를 한 번 눌러두면 브라우저 정책과 무관하게 알람이 정상 재생됩니다.
설정은 자동 저장됩니다.

화면 감지 알리미란?

화면 감지 알리미는 크롬에서 공유한 화면의 특정 영역을 분석해 사용자가 지정한 색상 범위나 기준 이미지와 감지 조건에 맞는 변화가 나타나면 소리로 알려주는 브라우저 도구입니다.

사용 방법

  1. 화면 공유 시작 버튼을 누르고 감지할 화면이나 창을 선택합니다.
  2. 감지 카드 추가 버튼을 눌러 감지 영역을 설정합니다.
  3. H는 색상, S는 채도, V는 명도 범위를 조정합니다.
  4. 감지 크기와 연속 감지 횟수를 설정해 원하는 조건을 지정합니다.
  5. 이미지 인식 모드에서는 [영역 캡처] 후 미리보기의 민트색 상자를 드래그해 기준 이미지를 지정하고 [저장]합니다. 유사도 기준(50~100%, 기본 99%) 이상이면 감지됩니다.
  6. 오디오 활성화 버튼을 누른 뒤 감지가 작동하는지 테스트합니다.

HSV란 무엇인가요?

HSV는 색상을 색상각도(Hue), 채도(Saturation), 명도(Value)로 표현하는 방식입니다. 이 도구에서는 H 범위를 0~360도로, S와 V 범위를 0~100%에 해당하는 값으로 조정할 수 있습니다.

개인정보 및 화면 공유

이 도구는 브라우저에서 화면 프레임을 분석하도록 작성되어 있습니다. 화면 공유는 사용자가 직접 선택하고 허용해야 합니다. 브라우저를 닫거나 공유를 중지하면 화면 감지가 중단됩니다.
